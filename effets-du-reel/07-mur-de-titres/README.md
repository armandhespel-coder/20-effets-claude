# Mur de gros titres

![Mur de gros titres](apercu.gif)

**À dire à Claude :** « Derrière moi, un mur de titres de presse qui défilent en biais. »

## Le refaire avec ta vidéo

1. Copie ce dossier.
2. Ajoute dedans :
- `cut.webm` = ta vidéo détourée (fond transparent).

Pour la version détourée, dis à Claude : « Détoure clip.mp4 et enregistre-le en cut.webm avec fond transparent ».
3. Dans le dossier : `npx hyperframes render --output effet.mp4`

Tu peux aussi juste ouvrir Claude Code dans ce dossier et lui dire : « Adapte cet effet à ma vidéo et change le texte en … ».
Format : vertical 720×1280, 5 secondes.
